## Iteration 1 – 17 July 2025

Search queries used:
1. "agentic AI study assistant high school 2025"
2. "educational game design high school engagement 2025 case studies"
3. "low-code platform create student productivity app"
4. "winning hackathon AI tutoring 2024"

Key take-aways & idea fragments:

• Agentic-AI tutors now combine long-term context + autonomous action (scheduling, reminders, unknown-question logging). Example: recent GPT-4o based tutor with Gradio front-end and Zapier/Google Calendar integration. → Opportunity: “PlannerPal” – an agentic study-planner that not only schedules sessions but nudges reflection, uses school calendar APIs, and logs hard questions for teacher review.

• Latest stats show top autonomous agents (Code Interpreter, AutoGPT, Kimi-Researcher) but also gaps: trust still low for factual answers; refusal highest for legal/medical. → Focus on narrow domain (school coursework) + supervised resources to raise trust.

• Gamified SRL tools (SRLAgent) improved self-regulated-learning skills via Zimmermann 3-phase loop + LLM scaffolding. → Idea: integrate SRL scaffolds into any Panda Hacks project; high schoolers need goal-setting + reflection.

• Games for Change 2025 high-school themes: eco-anxiety, animal advocacy, resilience. Shows appetite for purpose-driven educational games. → Could align with Hackathon Game Design track.

• Serious-game research (Tipping Point) stresses leverage-point thinking & collaboration. → We could design a cooperative board/digital game teaching study strategies or AI literacy.

Potential project directions:
1. StudySidekick – Agentic AI + SRL: chatbot that plans, adapts, and “levels-up” user through gameified quests; built with OpenAI functions + Supabase, front-end React.
2. QuestBoard – Cooperative web game where students manage virtual semester; agent suggests tasks while players balance wellbeing, deadlines (teaches time-management + resilience).
3. Low-Code Template Pack – Drag-and-drop Retool/Glide kit for teachers to spin up micro-apps (flashcards, reflection diary) without coding; agent auto-generates data schema.

Open questions:
• Which track (Agentic AI vs Game Design) scores best on judging criteria? (Impact & execution)
• Data privacy for minors; need easy opt-in guardian flow.
• Demo feasibility in hackathon timeframe – tutor MVP vs full game.
